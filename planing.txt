# Alfaprima
Planing setelah tamat dari alfaprima
(Awal Tamat)
1. Cari kerja entry level (IT Support, Admin IT, Data Entry, Junior Programmer).
2. Ikut kursus/sertifikasi tambahan (Office, Jaringan, Database, Web Development).
3. Ambil freelance/proyek kecil (website, jasa IT, UMKM).
(Penguatan Karir)
1. Tentukan fokus bidang (Programmer, Networking, Data Analyst).
2. Lanjut kuliah S1 (Primakara University).
3. Bangun portofolio (GitHub, LinkedIn, project pribadi).
